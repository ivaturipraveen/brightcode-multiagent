## Backend — Reservations API

### Routes added to existing FastAPI backend
- **File:** `backend/routes/wow_reservations.py`
- **Model:** `backend/models/wow_reservation.py`
- **Schema:** `backend/schemas/wow_reservation.py`
- **Prefix:** `/wow`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| POST | `/wow/reservations` | Public | Create reservation |
| GET | `/wow/reservations/availability` | Public | Check pod availability |
| GET | `/wow/reservations` | Admin token | List all |
| PATCH | `/wow/reservations/{id}` | Admin token | Update status |
| DELETE | `/wow/reservations/{id}` | Admin token | Delete |

- **Admin token:** `wow-admin-2025` (via `x-admin-token` header, or `WOW_ADMIN_TOKEN` env var)
- **Conflict detection:** 409 if pod already booked for same date+service
- **Language field stored:** en/it/zh
